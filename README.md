How the application works.
Campus Shop Inventory Management System is a simple Java application that helps a campus shop attendant keep track of products such as exercise books, pens, printing paper, flash disks and calculators.

 Records products with a Product ID, name, Product category, Unit price and Quantity in stock.
 Displays all products in a clear table
 Updates a product's price and stock
 Rejects invalid values like negative prices or stock
